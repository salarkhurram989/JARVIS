JARVIS PC Agent

End users do not need Python or Node.js. Install the packaged JARVIS-PC-Agent.exe from the GitHub Actions artifact. The agent listens only on 127.0.0.1:8765.

Features: system scan, safe app launching, file search, local memory, Google search and Git status. It intentionally does not expose arbitrary shell commands, deletion, shutdown/restart, or unrestricted process control.
