# JARVIS 🤖

A futuristic browser-based JARVIS personal assistant built with pure HTML, CSS and JavaScript.

## 🚀 Live Website

**https://salarkhurram989.github.io/JARVIS/**

If the link does not open immediately, enable **GitHub Pages** in the repository settings and select the `main` branch as the deployment source.

## Features

- 🎙️ Voice commands in Chrome
- 🔊 Spoken JARVIS responses
- 🕐 Live clock and date
- 🌐 Open Google, YouTube and GitHub
- 🔎 Google web search commands
- ⚡ Animated futuristic JARVIS interface
- 📱 Responsive desktop/mobile layout
- 🧩 No frameworks or external dependencies

## Example commands

- `What time is it?`
- `Open Google`
- `Open YouTube`
- `Open GitHub`
- `Search for Lamborghini`
- `Hello JARVIS`

## Built with

HTML • CSS • JavaScript • Web Speech API
